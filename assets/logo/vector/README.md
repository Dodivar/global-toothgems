# Logo masters (vector)

Reconstructed on 2026-11-02 from the PNGs in `assets/logo/`: the monogram's G is redrawn geometrically (constant 25° slant, regular corner radii), the sparkle made symmetric with its ~4° italic lean kept and shared by the monogram and the wordmark; the wordmark letters are a smoothed vector trace of `BLUE-LOGO.png`. Sparkle colour: the site's main blue `--gt-blue-300` (`#B9CDE5`).

| File | Use |
| --- | --- |
| `wordmark.svg` | ink letters, blue sparkle — light backgrounds (site header) |
| `wordmark-white-bluestar.svg` | white letters, blue sparkle — dark backgrounds |
| `wordmark-ink.svg`, `wordmark-white.svg`, `wordmark-blue.svg` | one colour |
| `monogram.svg`, `monogram-white.svg` | G + sparkle, ink or white G with blue sparkle |
| `monogram-ink.svg`, `monogram-white-solid.svg`, `monogram-blue.svg` | one colour |
| `app-icon.svg` | 512 px app icon (white tile, G and sparkle in the main blue); `app-icon-small.svg` for 16–48 px (thicker sparkle); the G is centred on the tile and the sparkle sits in its upper-right corner |
| `*-4000.png` | 4000 px exports for print and social networks |

Exports in the webapp: `app/favicon.ico`, `app/icon.svg`, `app/apple-icon.png`, `public/icons/`, `public/og-default.png`, `public/email/logo-wordmark.png`, `src/assets/logo-wordmark*.{svg,png}`.
